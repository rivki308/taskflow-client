# TaskFlow Pro – צד לקוח

מערכת לניהול משימות בצוות. מנהלת יוצרת פרויקטים ומשימות ומשייכת אותן לעובדים. עובדת רואה רק את המשימות שלה, מעדכנת סטטוס ומוסיפה הערות.

## טכנולוגיות
- React + TypeScript (Vite)
- React Router – ניווט בין עמודים
- React Hook Form – טפסים ו־Validation
- React Query – כל הקריאות לשרת
- Context – המשתמש המחובר

## הרצה מקומית
1. להפעיל את השרת לפי `backend-project/START-HERE.md`.
2. בתיקייה הזו:
   - `npm install`
   - ליצור קובץ `.env` עם השורה `VITE_API_URL=http://localhost:4000`
   - `npm run dev`
3. לפתוח את `http://localhost:5173`

## מסכים
- התחברות
- לוח בקרה – סיכום מספרים לפי תפקיד
- רשימת משימות – חיפוש, סינון, מיון ועימוד
- פרטי משימה – שינוי סטטוס, הערות, ולמנהלת עריכה ומחיקה
- יצירה ועריכה של משימה (מנהלת)
- עובדים (מנהלת)
- פרויקטים – רשימה, ולמנהלת יצירה ועריכה

## מבנה התיקיות
- `api/` – פונקציות שפונות לשרת
- `components/` – רכיבים משותפים
- `context/` – המשתמש המחובר
- `pages/` – עמוד לכל מסך
- `types/` – טיפוסי TypeScript
- `utils/` – פונקציות עזר ותרגומים
